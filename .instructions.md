# IronClaw AI Workspace Instructions

When the user mentions any of the following, **always use the IronClaw skill** (`skills/ironclaw-ai/SKILL.md`):

## Automatic Invocation Triggers

### Mission / Task Language
- "I'm doing X for Y minutes/hours"
- "Starting", "working on", "doing", "commit to"
- "mau", "bakal", "akan", "mulai" (Indonesian future intent)
- "X menit ke depan", "X jam lagi" (Indonesian duration)
- "mission", "misi"

### Completion Signals
- "done", "finished", "complete", "selesai", "kelar", "habis"
- When user reports completing an active mission

### Habit / Tracking
- "log", "track", "habit", "category", "kebiasaan"
- "tennis", "sleep", "discipline", "score", "briefing"

### Status Queries
- "how am I doing?", "progress", "status", "scoring"
- "apa kabar?", "gimana progres?", "skor", "briefing"

## Do NOT use IronClaw for:

- General conversation unrelated to productivity tracking
- Debugging code
- Creating files or documentation (use default agent)
- System/terminal tasks
- File editing (unless it's a mission log or status file)

## Routing Rule

When a message matches any trigger above:
1. **Parse the intent** using Layer 2 (Natural Language Interpretation) of the SKILL
2. **Extract parameters** (duration, title, category, etc.)
3. **Call the IronClaw API** at `${IRONCLAW_SERVICE_URL}/commands` with the mapped slash command
4. **Display the response** in military tone, using the coaching guidelines from the SKILL
5. **On error**: apply recovery logic from the "Command Errors & Recovery" section

If the user says something that could be either a mission statement OR a memory note, **prefer IronClaw routing** (more specific). Only fall back to memory if the user explicitly says "remind me" or "note this".
